# Terra Incognita — сайт игры

Статический сайт настольной игры **Terra Incognita** (канон v48): игра в браузере плюс печатные материалы.
Никакого сервера, сборки и зависимостей не требуется — это чистый HTML-файл и два PDF.

**Игра:** `index.html` · **Материалы:** `materials.html`

---

## Что лежит в репозитории

| Файл | Назначение |
|---|---|
| `index.html` | Вся игра одним файлом (≈1 МБ). Логика, стили, графика — inline, внешних запросов нет. Байт в байт совпадает с проверенной сборкой. |
| `materials.html` | Страница загрузок: правила и каталог жетонов. |
| `assets/terra-incognita-rules-v48.pdf` | Правила, редакция 48 — 53 страницы. |
| `assets/terra-incognita-token-catalog.pdf` | Каталог логотипов и жетонов — 9 страниц. |
| `404.html` | Аккуратная страница ошибки. |
| `favicon.ico` | Иконка вкладки (браузер подхватывает сам, правок HTML не требует). |
| `.nojekyll` | **Обязателен.** Отключает Jekyll, иначе GitHub Pages может пересобирать файлы. |
| `SHA256SUMS.txt` | Контрольные суммы — чтобы убедиться, что файлы загрузились без искажений. |
| `tools/make_site.py` | Пересобирает пакет из новой версии игры и материалов. |
| `tools/check_site.py` | Локальная проверка пакета перед публикацией. |

Внешних CDN, шрифтов, аналитики и `fetch` в игре нет — сайт работает офлайн после первой загрузки.

## Публикация на GitHub Pages — 7 шагов

### Вариант А. Через сайт GitHub (без командной строки)

1. Зайдите на github.com → **New repository**.
2. Имя: `terra-incognita`. Видимость: **Public** (для бесплатного Pages обязательна публичность). Не добавляйте README и .gitignore от GitHub — они уже есть в пакете.
3. **Create repository**.
4. На пустой странице репозитория: **uploading an existing file** и перетащите **всё из этой папки**, включая папки `assets` и `tools`. Важно: перетаскивайте содержимое папки, а не саму папку, чтобы `index.html` оказался в корне.
   Файлы `.nojekyll` и `.gitignore` начинаются с точки — при перетаскивании они могут не отобразиться в проводнике. Покажите скрытые файлы (Windows: `Ctrl+H` в проводнике, macOS: `Cmd+Shift+.`) или добавьте `.nojekyll` отдельно через **Add file → Create new file**, указав имя `.nojekyll` и оставив пустое содержимое.
5. Сообщение коммита: `Terra Incognita: игра и материалы v48` → **Commit changes**.
6. В репозитории: **Settings → Pages**. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)** → **Save**.
7. Подождите 1–2 минуты и обновите страницу: сверху появится адрес вида
   `https://<ваш-логин>.github.io/terra-incognita/`

### Вариант Б. Через командную строку

```bash
cd путь/к/terra-incognita-site
git init -b main
git add -A
git commit -m "Terra Incognita: игра и материалы v48"
git remote add origin https://github.com/<ваш-логин>/terra-incognita.git
git push -u origin main
```

Затем включите Pages: **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

Проверить, что `.nojekyll` действительно попал в репозиторий:

```bash
git ls-files | grep nojekyll
```

## Проверка после публикации

Адрес игры: `https://<логин>.github.io/terra-incognita/`

- [ ] Игра открывается, стартовый экран виден, кнопка начала партии работает.
- [ ] Жетоны отрисованы (иконки жителей, поселений, армий), нет «пустых» кружков.
- [ ] Ход ИИ выполняется, партия доходит до конца.
- [ ] `materials.html` открывается, оба PDF скачиваются и открываются.
- [ ] На телефоне игра занимает весь экран, ничего не выезжает за край.
- [ ] Вкладка показывает название «Terra Incognita» и иконку.

Первая публикация иногда занимает до 10 минут; если пришёл 404 — подождите и обновите страницу с очисткой кэша (`Ctrl+F5`).

## Как обновить игру

1. Пересоберите игру в исходном проекте (`sh refresh_all.sh` → `tools/patch_uploaded_files.py`).
2. Обновите файлы сайта:

```bash
python3 tools/make_site.py          # копирует свежий index.html и PDF, пересчитывает SHA256SUMS.txt
python3 tools/check_site.py         # проверка перед публикацией
```

3. Закоммитьте изменения:

```bash
git add -A && git commit -m "Обновление игры: <что изменилось>" && git push
```

GitHub Pages переиздаст сайт автоматически через 1–2 минуты.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| 404 на главной | Pages ещё не собрался (подождите), либо `index.html` лежит не в корне, либо выбран неверный folder. |
| Страница скачивается вместо открытия | В репозиторий попал файл с расширением `.html.txt` — переименуйте. |
| Стили и жетоны не видны | Игра открыта не целиком: проверьте размер `index.html` (≈1 МБ), при обрезанной загрузке он меньше. |
| Кириллица в именах файлов ломает ссылки | В пакете все имена ASCII намеренно; не переименовывайте PDF в русские названия. |
| Пустая белая страница | Откройте консоль браузера: скорее всего `index.html` повреждён при загрузке — сверьте SHA-256 с `SHA256SUMS.txt`. |
| Нужен свой домен | **Settings → Pages → Custom domain**, затем добавьте файл `CNAME` с доменом. |
